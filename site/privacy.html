SiliCool

Privacy

Short version: the app collects nothing, and it has no way to.

The app

SiliCool has no analytics, no telemetry, no crash reporting and no accounts. It contains no networking code at all, so sensor readings, fan speeds and machine details cannot leave your Mac even by accident. Your settings — the menu bar reading, your fan curve, whether the gauge animates — are stored in macOS's standard preferences on your own machine.

Fan control is performed by a small helper that runs locally on your Mac and talks only to SiliCool, over a channel where both ends verify each other's code signature. It has no network access either.

This website

There are no cookies, no trackers and no embedded third-party scripts other than the web font served by Google Fonts, which sees a request for the font file.

Like every website, the host serving these pages records ordinary access logs, which include visitor IP addresses. That is the only personal data involved anywhere in the project, it is collected by the host rather than by SiliCool, and it is not used to build any profile.

If that ever changes

It would be stated here and in the release notes before a version that did anything different was published.
